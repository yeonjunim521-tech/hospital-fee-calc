# 검색·방문 통계 운영 계약

## 상태

- 결정일: 2026-08-30
- 상태: 승인
- 대체 범위: 2026-07-11 개인정보·분석 설계의 `검색어를 aggregate로만 저장` 결정

## 목적

관리자가 실제로 입력된 검색어와 미결과 횟수를 확인해 공개 의료수가 항목을 보완한다. 방문량은 별도 익명 통계로 확인하되, 특정 방문자와 특정 검색어를 연결하지 않는다.

## 제품 동작

1. `기본 계산만 이용`을 선택하면 필수 조건을 이용한 기본 계산만 가능하다.
   방문·검색 로그는 전송하지 않으며 `aggregate` 대체 행도 만들지 않는다.
2. 검색과 선택 조건은 잠금 상태로 표시하고, 누르면 이용조건 dialog를 다시 연다.
3. 프로토타입 선택 기능을 이용하려면 자체 방문·검색 통계 수집에 필수로 동의해야 한다.
4. 실제 검색어는 `aggregate`로 대체하지 않는다.
5. 익명 방문 통계와 외부 분석 선택 상태는 검색어 통계와 분리한다.
6. 항목 클릭 총계는 운영 목적에 필요하지 않으므로 새로 수집하지 않는다.

## 프로토타입 선택 기능 필수 동의

- 목적: 프로토타입 선택 조건·추가 검색 제공, 미결과 항목 보완, 기능 확장 우선순위 결정, 동의 이용자의 방문 통계 집계
- 항목: 정규화된 실제 검색어, 검색 결과 유무·횟수·시각, 무작위 브라우저 ID의 일간 해시, 페이지 조회 수
- 보유·이용 기간: 수집일로부터 30일
- 거부 권리와 제한: 동의를 거부할 수 있다. 거부 시 필수 조건 기본 계산은 가능하지만 선택 조건과 추가 검색은 사용할 수 없다.
- 동의 버전: `medicost-consent-v3`. 기존 버전 선택은 새 계약의 동의로 간주하지 않고 다시 선택받는다.
- 자체 방문·검색 통계는 프로토타입 선택 기능 이용 시 필수다.
- 외부 Google Analytics는 기능 개발용 자체 통계와 다르므로 별도 선택으로 유지한다.

## 데이터 계약

### 검색어 통계

- 저장: 정규화된 실제 검색어, 검색 횟수, 미결과 횟수, 최초·최근 검색 시각
- 보존: 30일
- 금지: 방문자 ID, IP, 세션 ID, User-Agent와의 연결
- 보호: 이메일·전화번호·주민등록번호처럼 보이는 입력은 저장하지 않는다.
- 목적: 미결과 항목 확인, 항목 추가 우선순위 결정, 검색 품질 운영

### 방문 통계

- 저장: KST 일자, 일간 회전 익명 해시, 페이지 조회 횟수
- 보존: 30일
- 금지: 검색어 또는 계산 조건과의 연결
- 관리자 표시: 일자별 익명 방문자 수, 페이지 조회 수, 검색 횟수

## 관리자 계약

- `미결과`: 실제 검색어별 미결과 횟수, 최근 검색, 처리하기, 삭제
- `추가 완료`: 처리 이력, 삭제. 삭제해도 공개 의료수가 항목과 별칭은 유지한다.
- `전체 검색어`: 실제 검색어별 전체 검색 횟수, 미결과 횟수, 최근 검색, 삭제
- `방문자 통계`: 기간별 일간 익명 방문자·페이지 조회·검색 횟수
- 새 기록에 `aggregate`라는 가짜 검색어를 만들지 않는다. 기존 legacy 행은 사용자 목록과 집계에서 제외한다.

## 보존되는 기존 원칙

- Google Analytics에는 원시 검색어를 전송하지 않는다.
- 데이터는 30일 뒤 자동 삭제한다.
- 개인정보 처리 안내에 목적·항목·보유기간·철회 방법을 명시한다.
- 계산 공식과 공개 의료수가 데이터는 이번 결정으로 변경하지 않는다.
