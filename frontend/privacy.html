개인정보 처리 안내

서비스 분석은 선택하고 광고 처리는 확인할 수 있습니다

계산 기능과 정적 안내 페이지의 광고는 분석 동의 없이 작동합니다. 아래 내용은 현재 공개된 웹 코드의 동작을 기준으로 작성했습니다.

분석 설정 저장정보

브라우저의 localStorage에 `medicost-consent-v1` 이름으로 서비스 분석 선택값과 변경 시각을 저장합니다. 이 값은 분석 설정 화면을 반복 표시하지 않고 선택을 적용하는 데 사용됩니다. 이전 버전에 저장된 광고 선택값은 더 이상 사용하지 않습니다.

분석 동의 시

  • Google Analytics 방문·이용 통계
  • 자체 개선용 검색어, 검색 결과 수와 현재 경로
  • 검색 결과에서 클릭한 의료 항목의 코드와 이름
  • 계산 조건과 예상 금액의 구간값

자체 검색·클릭 로그는 30일 동안 저장하며 IP와 User-Agent는 저장하지 않습니다. 주민등록번호, 전화번호, 이메일 형태가 검색어·의료 항목·경로 중 하나에라도 포함되면 해당 로그를 저장하지 않습니다.

검색창에 이름, 연락처, 주민등록번호, 환자번호처럼 개인을 식별할 수 있는 정보를 입력하지 마세요.

Kakao AdFit 광고

광고 단위가 있는 정적 안내 페이지에서는 Kakao AdFit 광고 스크립트를 바로 불러옵니다. 메인 계산기와 사용자 입력·계산 결과 화면에는 광고 단위를 배치하지 않습니다.

광고 제공과 품질 측정 과정에서 카카오가 익명화된 인터넷 사용정보, 쿠키 또는 유사 기술을 수집·활용할 수 있습니다. 자세한 처리와 거부 방법은 카카오 개인정보 정책과 사용 중인 브라우저의 쿠키 설정에서 확인할 수 있습니다.

분석 설정과 보유기간

메인과 공통 안내 페이지 하단의 “분석 설정”에서 Google Analytics 사용 여부를 변경할 수 있습니다. 분석을 철회하면 이후 분석 스크립트와 telemetry 전송을 중단합니다.

선택 분석 로그는 수집일로부터 30일이 지난 뒤 다음 일일 삭제 작업에서 제거합니다. 브라우저 저장정보를 삭제하면 다음 방문 시 분석 설정을 다시 묻습니다.

광고 쿠키는 브라우저 설정에서 차단하거나 삭제할 수 있습니다. 데이터 오류와 개인정보 문의 채널은 준비 중이며, 상업 공개 전 운영 주체와 공식 연락처를 이 페이지에 표시해야 합니다.
