스캔을 중단하고 확인된 보안 문제를 실제 코드로 수정 중이다. 관리자 POST 동일 출처 검증, 공개 검색어 원문 제거, 클릭 로그 제한·개인정보 차단·비식별 총계화, 질병 검색 XSS 방어를 반영했다.
